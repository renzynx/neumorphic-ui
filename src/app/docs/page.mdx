# Introduction

Welcome to the Neumorphic UI component library. This library provides a collection of accessible, customizable React components built with Base UI and styled with a soft, neumorphic design system.

## Features

- **Neumorphic Design** - Soft shadows and subtle depth create a modern, tactile interface
- **Accessible** - Built on Base UI primitives for robust keyboard navigation and screen reader support
- **Customizable** - Easy to customize with CSS variables and Tailwind classes
- **Dark Mode** - Full dark mode support with carefully tuned color palettes
- **TypeScript** - Full TypeScript support with exported types

## Getting Started

Browse the components in the sidebar to see examples and usage instructions for each component.
